参数说明
行号 / 简称 MFMLIN / MFMSHO
行号标识该颜色（结果里回传为 color），简称用于页面显示与核对。名称 MFMDES 不在此页展示。
X1 / X2 / X3
AB、EF、GH 三组的牵伸倍数，由算法求解；CD 组固定为 1.00。同一组内两个桶位同速。
xmin / xmax
三个牵伸倍数的搜索边界，需满足 xmin ≥ 1.0 且 xmax > xmin。范围越窄越快，越宽越容易找到解。
色比 MATRATCALC
每种颜色希望占的比例。数值本身不重要，只看相对大小；均为 0 时无法计算。
优先色 PRIORITY
勾选后该颜色误差需 ≤ 0.05%，普通颜色 ≤ 0.5%。达标的方案排在前面。
固定桶位 POSITION
选中后该颜色只能出现在这些桶位，留空表示不限。组内两格同速，具体落位由相邻同色最少的排布决定。
maxtime
搜索时间上限（秒）。到时停止，返回已找到的方案；颜色多或范围宽时可调大。
seed
随机种子。相同输入与种子会得到相同结果，便于对比和复现。
